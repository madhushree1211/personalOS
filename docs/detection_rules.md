# Detection Rules

The detection rules evaluate existing audit events without database access in the engine.

| Rule | Audit event | Threshold | MITRE technique |
|---|---|---:|---|
| brute-force-login | `login-failed` | 5 within 300 seconds per IP | T1110 - Brute Force |
| repeated-capability-denials | `permission-denied` | 5 within 300 seconds per user | T1548 - Abuse Elevation Control Mechanism (closest match, approximate) |
| cross-user-resource-access | `supervisor-policy-denied` | 3 within 300 seconds per user | T1068 - Exploitation for Privilege Escalation (closest match, approximate) |
| repeated-mfa-failures | `investment-mfa-failed` | 3 within 300 seconds per user | T1111 - Multi-Factor Authentication Request Generation (closest match, approximate) |

MITRE mappings are informational. Where the application event is not an exact match for an ATT&CK behavior, the table is an explicit closest match, approximate mapping.

The simulator is synthetic. Its labeled scenarios and metrics are generated by this repository and are not real-world performance measurements.
